# Gantt

A timeline visualization component for displaying time-based events and intervals. Virtualized along both the horizontal and vertical axes for performance.

## Container Components

- **`GsGantt`** - Root component that manages timeline state, layout, and virtualization
- **`GsGanttContentContainer`** - Houses timeline content rows
- **`GsGanttPanelContainer`** - Houses metadata panel that aligns with timeline rows

## Row Components

- **`GsGanttContentRow`** - Displays timeline elements with virtualization support
- **`GsGanttPanelRow`** - Displays metadata that corresponds to a `GsGanttContentRow`

## Timeline Elements

- **`GsGanttBlock`** - Time interval displayed as a solid block (can contain content in its default slot)
- **`GsGanttSpacer`** - Time interval displayed as a horizontal line
- **`GsGanttMarker`** - Vertical line marking a single point in time
- **`GsGanttIconMarker`** - Vertical marker with an icon
- **`GsGanttBracketOpen`** - Opening bracket for a time interval
- **`GsGanttBracketClose`** - Closing bracket for a time interval

### Dataset-driven Display

Example using these hypothetical dataset typings:

```ts
import type { GsGanttRowElementColor } from '@wingbrace/glideslope'

type RangeTuple = readonly [startMs: number, endMs: number]

type Element =
  | { type: 'block'; rangeMs: RangeTuple; color?: GsGanttRowElementColor }
  | { type: 'spacer'; rangeMs: RangeTuple; color?: GsGanttRowElementColor }
  | { type: 'bracket-open'; timeMs: number; color?: GsGanttRowElementColor }
  | { type: 'bracket-close'; timeMs: number; color?: GsGanttRowElementColor }
  | { type: 'marker'; timeMs: number; color?: GsGanttRowElementColor }
  | { type: 'icon-marker'; timeMs: number; color?: GsGanttRowElementColor }

type Row = {
  id: string
  elements: Element[]
  trackNumber: string
  description?: string
}

type Dataset = {
  startTimeMs: number
  endTimeMs: number
  rows: Row[]
}
```

```vue
<script setup lang="ts">
import {
  GsGantt,
  GsGanttBlock,
  GsGanttBracketClose,
  GsGanttBracketOpen,
  GsGanttContentContainer,
  GsGanttContentRow,
  GsGanttIconMarker,
  GsGanttMarker,
  GsGanttPanelContainer,
  GsGanttPanelRow,
  GsGanttSpacer,
  GsIcon,
  type GsGanttMetThresholdData,
  type GsGanttThreshold,
} from '@wingbrace/glideslope'
import { PlaceholderIcon } from '@wingbrace/glideslope-icons'

const { dataset } = defineProps<{ dataset: Dataset }>()

// Wed Jan 28, 2026 at 22:00 UTC
const currentTimeMs = 1769637600000
const timescale = '2h'

const threshold: GsGanttThreshold = {
  timescaleMultipleDistance: 3,
  rowIndexBoundaryDistance: 2,
}

function onThresholdMet(metThresholds: GsGanttMetThresholdData[]) {
  console.log(metThresholds)
}

const twoDigits = (value: number) => value.toString().padStart(2, '0')

function timestampLabel(startTimestampMs: number, endTimestampMs: number) {
  const start = new Date(startTimestampMs)
  const end = new Date(endTimestampMs)

  return `${twoDigits(start.getUTCHours())}:${twoDigits(start.getUTCMinutes())}--${twoDigits(end.getUTCHours())}:${twoDigits(end.getUTCMinutes())}`
}
</script>

<template>
  <div class="h-[480px]">
    <GsGantt
      :start-time-ms="dataset.startTimeMs"
      :end-time-ms="dataset.endTimeMs"
      :current-time-ms="currentTimeMs"
      :timescale="timescale"
      :threshold="threshold"
      @threshold-met="onThresholdMet"
    >
      <GsGanttPanelContainer>
        <GsGanttPanelRow v-for="row in dataset.rows" :key="row.id">
          <div class="flex items-center font-display text-body-s fg-primary-bold">
            <span>{{ row.trackNumber }}</span>
            <span v-if="row.description" class="fg-inverse-muted"
              >&nbsp;- {{ row.description }}</span
            >
          </div>
        </GsGanttPanelRow>
      </GsGanttPanelContainer>
      <GsGanttContentContainer>
        <GsGanttContentRow v-for="row in dataset.rows" :key="row.id">
          <template
            v-for="(element, index) in row.elements"
            :key="`${row.id}-${element.type}-${index}`"
          >
            <GsGanttBlock
              v-if="element.type === 'block'"
              :id="`${row.id}-block-${index}`"
              :start-time-ms="element.rangeMs[0]"
              :end-time-ms="element.rangeMs[1]"
              :color="element.color"
            >
              <div
                v-if="element.color === 'critical' || element.color === 'serious'"
                class="flex flex-col text-body-xs"
              >
                <span>JAMMING ENTRY</span>
                <span>{{ timestampLabel(element.rangeMs[0], element.rangeMs[1]) }}</span>
              </div>
            </GsGanttBlock>
            <GsGanttSpacer
              v-else-if="element.type === 'spacer'"
              :id="`${row.id}-spacer-${index}`"
              :start-time-ms="element.rangeMs[0]"
              :end-time-ms="element.rangeMs[1]"
              :color="element.color"
            />
            <GsGanttBracketClose
              v-else-if="element.type === 'bracket-close'"
              :time-ms="element.timeMs"
              :color="element.color"
            />
            <GsGanttBracketOpen
              v-else-if="element.type === 'bracket-open'"
              :time-ms="element.timeMs"
              :color="element.color"
            />
            <GsGanttMarker
              v-else-if="element.type === 'marker'"
              :time-ms="element.timeMs"
              :color="element.color"
            />
            <GsGanttIconMarker
              v-else-if="element.type === 'icon-marker'"
              :time-ms="element.timeMs"
              :color="element.color"
            >
              <GsIcon size="small"><PlaceholderIcon /></GsIcon>
            </GsGanttIconMarker>
          </template>
        </GsGanttContentRow>
      </GsGanttContentContainer>
    </GsGantt>
```

<ArgTypes of={GsGantt} />

#### `threshold` and `threshold-met`

The Design Toolkit's `thresholdProps` object is split in two: the `threshold` prop turns threshold examination on, and the `threshold-met` event delivers the thresholds that were met.

| Property                              | Type                                                 | Description                                                                                                    |
| ------------------------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `threshold.timescaleMultipleDistance` | `number`                                             | Number of timescale units from the timeline boundaries that triggers threshold events (e.g., for data loading) |
| `threshold.rowIndexBoundaryDistance`  | `number`                                             | Number of rows from the visible row boundaries that triggers threshold events                                  |
| `@threshold-met`                      | `(metThresholds: GsGanttMetThresholdData[]) => void` | Emitted when rendered region approaches timeline or row boundaries                                             |

##### `GsGanttMetThresholdData` Object

| Property    | Type                         | Description                                                                 |
| ----------- | ---------------------------- | --------------------------------------------------------------------------- |
| `axis`      | `'horizontal' \| 'vertical'` | Indicates whether the threshold was met on the time axis or row axis        |
| `direction` | `'start' \| 'end'`           | Indicates whether the threshold was met at the beginning or end of the axis |
| `value`     | `number`                     | The value at which the threshold was met                                    |

Only **newly met** thresholds are emitted. A threshold that stays met with the same value (same axis, direction and value) is emitted again only after the rendered region leaves and re-enters it, or when its value changes (because `startTimeMs`, `endTimeMs`, `timescale` or `threshold` changed). The scroll position starts at the middle of the time range, so the start threshold isn't met on mount. When the whole time range fits in view (for example after zooming out to `24h`), both temporal thresholds are met at once; the app might then provide a wider range of data.

## Important Notes

### Component Structure

The Gantt chart follows a specific structure that must be maintained:

```
GsGantt
├── GsGanttPanelContainer
│   ├── GsGanttPanelRow
│   └── GsGanttPanelRow
└── GsGanttContentContainer
    ├── GsGanttContentRow
    │   └── Row elements (e.g., `GsGanttBlock`, `GsGanttMarker`, etc.)
    └── GsGanttContentRow
        └── Row elements (e.g., `GsGanttBlock`, `GsGanttMarker`, etc.)
```

Rows must be direct children of their container's default slot (a `v-for` is fine), since the containers read the slot as a list of rows to virtualize it.

### Fixed Row Height

The Gantt layout relies on a shared row height (`rowHeightPx`) so that:

- panel rows align exactly with timeline rows
- vertical virtualization calculations remain stable
- scroll synchronization stays pixel-perfect

Row components (`GsGanttPanelRow`, `GsGanttBlock`) therefore **do not expand to fit content** and will hide overflow.

When composing row content, treat available vertical space as a fixed container.

### Temporal Position Anchoring

When new data is rendered (determined by changes to `startTimeMs` or `endTimeMs`), the Gantt maintains the user's temporal position:

- **Within range**: If the current scroll position timestamp falls within the new data range, the timeline remains anchored to that same timestamp. Users experience no jump in perceived time position.
- **Outside range**: If the current timestamp is outside the new data range, the scroll position resets to `startTimeMs`.

This ensures a stable user experience during dynamic data loading scenarios.

### Virtualization

The Gantt component implements virtualization for both vertical and horizontal axes to improve performance when handling large datasets.

#### Vertical Virtualization

The vertical virtualization is implemented using an overscan strategy, where the component renders a few extra rows above and below the visible viewport to ensure smooth scrolling and prevent visual artifacts. The total scrollable height is calculated as `rowHeightPx` multiplied by the total number of rows (plus the height of the horizontal scrollbar). As the user scrolls, the rendered rows reflect the updated scroll position.

#### Horizontal Virtualization

The horizontal virtualization works by dividing the timeline into fixed-width chunks. The component calculates how many chunks are needed to fill the visible viewport, then adds buffer chunks on either side for smooth scrolling. Each chunk's fixed pixel width represents a specific time duration determined by the current `timescale` value.

The rendered region spans from the first chunk's timestamp to the last chunk's timestamp plus its duration. Row elements (`GsGanttBlock`, `GsGanttMarker`, etc.) are rendered by comparing their timestamps against this rendered region. Rendering only the row elements that fall within the rendered region ensures efficient performance.

The `startTimeMs` and `endTimeMs` props on the root `GsGantt` component are used to determine the entire scrollable region of the component. As the user scrolls, the rendered region changes to reflect the new scroll position.

#### Rendering cost while scrolling

Scrolling updates a small per-chart store on every frame, but components only re-render when the scroll crosses a row (the rendered rows change) or a timescale interval (the timeline chunks and rendered region change). The timeline and the current-time marker follow the scroll position every frame by writing a CSS variable in an animation frame, without re-rendering.

### Keyboard and screen readers

Both scroll containers take focus, so keyboard users can scroll the chart: the chart itself (a region named "Gantt chart") scrolls the rows with the up and down arrows, and its timeline (a group named "Timeline") scrolls time with the left and right arrows. Name the chart for its content with an `aria-label` on `GsGantt`:

```vue
<GsGantt aria-label="Strike package timeline" … />
```

## Best Practices

- Maintain the same number and order of `GsGanttPanelRow` and `GsGanttContentRow` components
- For large datasets (many rows or time spans), use the `threshold` prop and `threshold-met` event for dynamic data loading
- Set appropriate time boundaries with `startTimeMs` and `endTimeMs` props on the root `GsGantt` component that encompass all your timeline elements (set `startTimeMs` earlier than your earliest element and `endTimeMs` later than your latest element)
- Choose a `timescale` that provides the right level of detail for your data
- Keep large datasets out of deep reactivity: hold them in a `shallowRef` (or `markRaw` them), and replace them rather than mutating them, so Vue doesn't track every row and element
