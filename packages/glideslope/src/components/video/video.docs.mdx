# Video

`GsVideo` wraps an HTML `<video>` element with [media controls](?path=/docs/components-mediacontrols--docs), providing playback controls, seek functionality, volume control, playback rate adjustment, fullscreen support, and visual overlays for loading and error states.

Built on [media-chrome](https://www.media-chrome.org/) for state management and accessibility.

It is composed of the following components:

- **GsVideo** - Main video player component with integrated controls
- **GsPlayButton** - Play/pause toggle button
- **GsMuteButton** - Mute/unmute toggle button
- **GsVolumeSlider** - Volume level slider
- **GsTimeRange** - Seek/scrub bar for video position
- **GsTimeDisplay** - Current time or duration display
- **GsSeekButton** - Skip forward/backward button
- **GsPlaybackRateButton** - Playback speed selector
- **GsFullscreenButton** - Enter/exit fullscreen toggle button

## Example usage

```vue
<!-- Basic usage -->
<GsVideo src="video.mp4" />

<!-- With poster image -->
<GsVideo src="video.mp4" poster="thumbnail.jpg" />

<!-- With event listeners -->
<GsVideo
  src="video.mp4"
  @ended="console.log('Ended')"
  @time-update="(time) => console.log('Current time:', time)"
  @error="(error) => console.error('Video error:', error)"
/>

<!-- Custom controls layout -->
<GsVideo src="video.mp4">
  <GsMediaControls class="gap-s">
    <GsPlayButton />
    <GsTimeRange />
    <GsMuteButton />
    <GsFullscreenButton />
  </GsMediaControls>
</GsVideo>

<!-- Disable keyboard shortcuts (e.g. when inside a form) -->
<GsVideo src="video.mp4" no-hotkeys />

<!-- Disable preference persistence -->
<GsVideo src="video.mp4" no-volume-pref no-muted-pref />
```

Classes on `GsVideo` itself go on the outer `media-controller` element (the Design Toolkit's `classNames.container`).

### Media Controller Props

These props configure the underlying media-chrome `<media-controller>`:

- `noHotkeys` disables all keyboard shortcuts (Space plays and pauses, the arrow keys seek and change the volume, `m` mutes, `f` toggles fullscreen). Useful when embedding in forms or apps with their own hotkey system.
- `hotkeys` turns off individual shortcuts, such as `noarrowleft noarrowright`. See [media-chrome's keyboard shortcuts](https://www.media-chrome.org/docs/en/keyboard-shortcuts).
- `noVolumePref` and `noMutedPref` stop the volume level and muted state from being saved to `localStorage` across page loads.
- `lang` sets the language of media-chrome's built-in accessibility labels. media-chrome keeps one language for the whole page.

## Implementation Notes

`GsVideo` wraps the HTML `<video>` element and uses media-chrome for state management. It renders a [GsMediaController](?path=/docs/components-mediacontrols--docs), so control components in its default slot can access the media state without additional setup, and are disabled with it.

### Default Controls

`GsVideo` includes a full set of controls arranged in two rows:

- **Time row**: Current time display, seek bar, duration display
- **Controls row**: Mute button, volume slider, seek backward, play/pause, seek forward, playback rate, fullscreen

### Visual Overlays

The component renders visual overlays for loading and error states, also with custom controls:

- **Loading overlay**: Shown while video metadata is loading or media is buffering
- **Error overlay**: Shown when the video fails to load, with an error message describing the failure

[media-chrome Docs](https://www.media-chrome.org/docs)

The underlying elements are:

- `media-controller` for the accessible media chrome container, which is also the element that goes fullscreen
- `video` element for the actual video playback, set through its `src` attribute so a failed load reports a `MediaError`
- The control components (`GsPlayButton`, `GsTimeRange`, `GsFullscreenButton`, …) for user interaction

The component handles accessibility features including:

- ARIA attributes for screen readers
- Keyboard navigation for all controls
- Focus management
- Proper labeling of interactive elements
- A status for loading and an alert when the video fails to load
