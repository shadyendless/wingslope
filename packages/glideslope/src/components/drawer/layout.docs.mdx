# DrawerLayout

A CSS Grid-based layout system for positioning panels on any side of the main content area. Shared layout primitive used by [Drawer](?path=/docs/components-drawer--docs) and [Sidenav](?path=/docs/components-sidenav--docs).

<Canvas of={DrawerLayoutStories.Default} />

## Example Usage

```vue
<GsDrawerLayout extend="left right" push="left">
  <GsDrawerLayoutMain>
    <!-- Main content area -->
  </GsDrawerLayoutMain>

  <!-- GsDrawer, GsSidenav, or other panel components -->
</GsDrawerLayout>
```

## How `extend` Works

```
extend: 'left right' (default)        extend: 'top bottom'
┌──────┬──────────┬───────┐           ┌─────────────────────────┐
│      │   top    │       │           │          top            │
│      ├──────────┤       │           ├──────┬──────────┬───────┤
│ left │   main   │ right │           │ left │   main   │ right │
│      ├──────────┤       │           ├──────┴──────────┴───────┤
│      │  bottom  │       │           │         bottom          │
└──────┴──────────┴───────┘           └─────────────────────────┘
```

## How `push` Works

| Value                     | Behavior                                 |
| ------------------------- | ---------------------------------------- |
| `undefined`               | Panels float over main content (overlay) |
| `'left'`                  | Left panel pushes content to the right   |
| `'left right'`            | Both side panels push content            |
| `'top bottom left right'` | All panels push content from all sides   |

## Implementation Notes

- Built with CSS Grid for layout management
- Layout responds automatically to panel open/close states: each open `GsDrawer` sizes its edge's track, and a `GsSidenav` reserves the left track for its rail
- Must include exactly one `GsDrawerLayoutMain` component
- Drawers and the sidenav must be direct children of the layout
